# src/emu — vendored emulator core

These files were copied from git submodules so the project builds as a plain Arduino sketch.
Arduino compiles every `.c`/`.cpp` under `src/` recursively, so only the files needed by the firmware are included.

| Origin | Commit |
| --- | --- |
| [likeablob/umac](https://github.com/likeablob/umac) (branch `likeablob/feat-esp-support`, fork of [evansm7/umac](https://github.com/evansm7/umac)) | `8f49e71` |
| [evansm7/Musashi](https://github.com/evansm7/Musashi) (umac's `external/Musashi`) | `b3144f1` |

## Local changes vs. upstream

- `umac_main.c` (umac `src/main.c`, renamed): removed the ESP IPC hooks (`umac_ipc.h`), `MOUSE_MAX_PENDING_PIX` 30 → 400 → made overridable via `../user_config.h` (default 64), error output via `printf`.
- `disc.c`: `SonyOpen` derives drive type / sides / block count from the image size (large HFS images), eject debug logging, `printf` output.
- `rom.c`, `scc.c`, `via.c`: error output via `printf`.
- `m68kconf.h`, `machw.h`: project versions (ESP32 `IRAM_ATTR` fast functions, framebuffer split into internal RAM; `machw.h` pulls settings from `../user_config.h`).
- `m68kops.c` / `m68kops.h`: generated by Musashi's `m68kmake` and decorated with `M68K_FAST_FUNC` by umac's `tools/decorate_ops.py`.
- Renamed for the Arduino build: `m68kfpu.c` → `m68kfpu.c.h` (it is `#include`d by `m68kcpu.c`, not compiled on its own), `softfloat-macros` / `softfloat-specialize` → `.h`, with matching `#include` updates.
